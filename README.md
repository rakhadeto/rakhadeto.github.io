# 🌐 Naufal Rakhadeto — Portfolio Website

> Personal portfolio website built with pure HTML, CSS, and JavaScript — featuring a cyberpunk-inspired dark UI with glowing cyan accents, smooth animations, and a fully responsive layout.

🔗 **Live Site:** [rakhadeto.github.io](https://rakhadeto.github.io)

---

## ✨ Features

- **Custom Cursor** — animated glowing cursor with magenta hover effect
- **Glitch Animation** — hero name with cyberpunk glitch effect
- **Scroll Reveal** — elements animate in as you scroll
- **Animated Grid Background** — subtle moving grid overlay
- **Fully Responsive** — works on mobile, tablet, and desktop
- **Smooth Scrolling** — seamless navigation between sections

---

## 🚀 Getting Started

Clone the repo and open locally:

```bash
git clone https://github.com/rakhadeto/rakhadeto.github.io.git
cd rakhadeto.github.io
# Open index.html in your browser
```

No build tools or dependencies needed — pure HTML/CSS/JS.
